The customer link opens a clean REPAY payment page. The customer can use a compatible UPI app on their device.

Important: This starter version saves UPI accounts only in this browser on this device. The admin page is not protected by a secure login, and a static GitHub Pages site cannot keep admin details private. For real private admin access, multi-device syncing and verified payment status, a secure backend/payment gateway is required.
